# Python-клиент для Cropwise API

[Read in English](README.md)

Библиотека-обертка на Python для работы с **Cropwise Operations (Cropio) API v3**, поддерживающая автоматическую пагинацию, повторные попытки запросов и опциональные возможности обработки пространственных ГИС-данных.

> ⚠️ **Статус разработки: Бета-версия**  
> Данная библиотека находится на **стадии бета-тестирования**. Она полностью стабильна для уже реализованных эндпоинтов, но кодовая база продолжает активно развиваться. В будущих релизах будут добавлены новые эндпоинты Cropwise API, а по мере стабилизации архитектуры возможны незначительные изменения в синтаксисе методов.

## ✨ Поддерживаемые эндпоинты API и возможности

Библиотека предоставляет прямой доступ к определенным эндпоинтам Cropwise Operations API v3, возвращая структурированные данные в формате таблиц `pandas.DataFrame`:

- **Базовые справочники инфраструктуры:** 
  - `fields`
  - `machines` и `machine_groups` (реестр техники и ее классификация)
  - `implements` (прицепное и навесное оборудование)
  - `crops` и `work_types` (справочники сельскохозяйственных культур и видов агроопераций)
  - `users` (список пользователей системы внутри компании)
  - `agro_operations`
  - `machine_tasks`
  - `machine_task_agro_operation_mapping_items` (связи между задачами техники и агрооперациями)
  - `machine_task_field_mapping_items` (связи между задачами техники и конкретными полями)
  - `gps_logger_data_items` (сырые пространственные GPS-координаты треков)
  - `gps_logger_event_data_items` (телематические логи датчиков техники, такие как уровень топлива или обороты двигателя)
  - `history_items`
  - `inventory_history_items`

### Расширение для экспорта в ГИС
- Включает опциональный модуль `processing`, использующий возможности `geopandas` и `shapely` для компиляции многодневных треков или отдельных рабочих смен в непрерывные векторные геометрии `LineString` с их последующим сохранением в файлы стандартного формата `GeoPackage (.gpkg)` для QGIS и ArcGIS.

## 📦 Установка

По умолчанию устанавливается базовый легковесный клиент для работы исключительно со структурами данных и таблицами:

```bash
pip install cropwise-api-client
```

Для установки полной геопространственной версии, содержащей ГИС-модуль `processing`:
*(Примечание: Пользователям операционной системы Windows настоятельно рекомендуется запускать этот пакет внутри **OSGeo4W Shell** или встроенного **Python-окружения QGIS**, чтобы избежать ошибок несовместимости скомпилированных бинарных ГИС-библиотек).*

```bash
pip install cropwise-api-client[gis]
```

## 🚀 Быстрый старт

### 1. Инициализация клиента (Рекомендуемый способ через постоянный токен)

Сгенерируйте постоянный API-токен в профиле Cropwise Operations и используйте его для безопасного подключения без раскрытия основного пароля аккаунта в коде:

```python
from cropwise import CropwiseClient

# Инициализация клиента с помощью постоянного токена пользователя
client = CropwiseClient(token="ваш_токен")

# Получение списка всех полей в виде DataFrame с индексацией по ID
df_fields = client.get_fields()
print(df_fields[['id', 'name']])
```
```

### 2. Экспорт трека техники в GeoPackage (.gpkg) для QGIS

Выгружайте сырые GPS-логи телеметрии, пересекающие границы календарных суток или ночные рабочие смены, с автоматической сборкой в единую векторную линию:

```python
from datetime import datetime
from pathlib import Path
from cropwise import CropwiseClient
from cropwise.processing import build_machine_track_gpkg

client = CropwiseClient(token="ваш_токен")

# Извлечение точек телеметрии и запись слоя LineString прямо на диск
build_machine_track_gpkg(
    client=client,
    machine_id=1299,
    dt_from=datetime(2026, 10, 20, 20, 0, 0),  # Начало ночной смены
    dt_to=datetime(2026, 10, 21, 8, 0, 0),    # Конец ночной смены
    output_gpkg=Path("C:/GIS_Data/tracks/night_shift_1299.gpkg"),
    machine_name="John Deere 8R"
)
```

### 3. Извлечение данных с датчиков телематики

Выгружайте показания конкретных датчиков. Библиотека автоматически развернет вложенные динамические структуры JSON в плоские классические колонки таблицы:

```python
from cropwise import CropwiseClient

client = CropwiseClient(token="ваш_токен")

# Получение логов уровня топлива, оборотов и внешнего питания для списка машин
df_telemetry = client.get_logger_event_data(
    date_at="2026-10-23",
    machine_ids=[101],
    params=["fuel_level", "engine_speed", "pwr_ext"]
)
print(df_telemetry.head())
```
